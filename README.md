# Coding Practice Problems

A collection of small Python scripts and coding practice problems.

## Structure

- `2026_problem/` — practice problems (LeetCode-style), one file per problem,
  each with the problem statement and one or more solution approaches
  documented in comments.
- Root-level `.py` files — standalone scripts (string/list manipulation,
  math helpers, small utilities, etc).

`index.html` is published via GitHub Pages at https://dmitra100.github.io/.
